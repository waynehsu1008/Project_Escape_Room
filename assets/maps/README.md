## 使用與驗證

- 四張圖以固定俯視角與平行地板格呈現，保留連通空地供上下左右探索；不包含角色、UI 或解答文字。
- 已逐張目視檢查：完整單一地圖、無人物、中央通路、出入口與家具區可辨識；已讀取確認四張皆為 1536×1024。
- 為整張光柵背景，不是可重組的 tileset，也沒有獨立家具圖層。畫面地磚為美術元素，未驗證為精確等距的程式碰撞網格。
- 建議將 PNG 作背景，角色、互動熱區、家具碰撞、地圖切換與前景遮擋由遊戲程式另外配置；角色不能穿過桌椅與牆壁的功能尚未實作或試玩驗證。
- 此批是使用者要求的四張地圖候選素材。BRIEF.md 目前仍為舊教室、走廊資料區、廣播室三場景草稿；本次沒有替換劇情場景、增加關卡或修改故事資料。
- 每張完整生成提示詞存於相同名稱的 .prompt.txt，保留要求與實際生成結果的差異供後續調整。
