# 不存在的第八節課

一款純前端校園密室逃脫遊戲。你是 2026 年整理舊校舍的校史志工，在一間沒有下課的教室裡，找回一位同學未完成的告別。

第一版包含三個可往返場景、三道主要謎題、背包與道具使用、最後點名、八次敘事鐘聲、單一結局及此瀏覽器的自動存檔。沒有倒數或答錯死亡；可以慢慢讀，也能靜音玩。

## 直接線上遊玩（免安裝）

**遊戲網址：[https://waynehsu1008.github.io/Project_Escape_Room/](https://waynehsu1008.github.io/Project_Escape_Room/)**

組員與玩家直接用電腦或手機瀏覽器開啟這個網址即可，不需要 Node.js、終端機、下載專案或 GitHub 帳號。這是 GitHub Pages 的公開遊戲網站；GitHub 倉庫頁面是原始碼管理頁，不是遊戲入口。

進度分別保存在每位玩家自己的瀏覽器；不會與組員共用同一份存檔。

## 本機開發與測試（開發者使用）

Windows 可直接雙擊專案根目錄的 `Start-Game.cmd`，再開啟 http://127.0.0.1:4173/。遊玩期間保留啟動視窗，結束後按 Ctrl+C。啟動器優先使用 PATH 中的 Node.js；未找到時會嘗試本機 Codex 隨附的 Node.js，不需要 npm。

需要 Node.js 20 以上；無須安裝第三方套件。

在本專案目錄執行：

```sh
node scripts/serve.mjs
```

開啟 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。也可使用 `npm start`。伺服器只監聽本機；不要直接以檔案方式雙擊 index.html，因為瀏覽器會限制讀取故事 JSON。

此本機網址只供開發者測試，只有在自己的電腦執行伺服器時可用。分享給組員或玩家時，請使用上方 GitHub Pages 網址。

## 操作方式

校園擴充：三場景各有一位能交談的同行者——周伯、許學長、小禾，每人提供三個話題，開場對話隨故事進度改變。地圖也新增九個可查看的校園物件與生活痕跡，部分標記看似可疑，查看後可分辨其日常用途。這些觀察不占必要背包、不增加鐘聲，不必全部查看也能完成原本逃脫路線；讀過的物件與人物概況會留在探索筆記。

| 操作 | 方法 |
| --- | --- |
| 移動 | 方向鍵 ↑ ↓ ← →；亦支援 WASD、點擊地面走路與手機方向按鈕 |
| 與物件互動 | 走近按 E；或點擊物件標記，角色會先走近再互動 |
| 查看背包 | 按 B 或點擊右側背包；文件可以重讀 |
| 使用道具 | 查看道具→拿起→點擊場景目標；也可在附近目標的視窗直接選擇道具 |
| 關閉視窗 | Esc 或右上角關閉按鈕；閱讀與輸入時角色暫停移動 |
| 取得提示 | 點「需要一點方向」，或在謎題中逐層展開，最多三層 |
| 音效與設定 | 右上角開關合成鐘聲、查看說明、手動儲存或確認重新開始 |

機關打開後還需要逐件拾取。開過的門可以走回去，漏拿的必要物品能補取；用錯道具不會消耗物品。最後點名完成只會開出口，請親自走出校舍。

## 存檔

進度儲存在同一瀏覽器、同一網址來源的 localStorage。行動後與探索途中會保存；再次開啟可選擇繼續。更換瀏覽器、清除網站資料或改用另一個連接埠，不會自動帶入原存檔。無法保存或存檔不相容時，介面會提示。

角色名稱用於責任劃分，並非真實 Git 提交身分。此第一版由本對話依使用者完整遊戲要求製作，團隊組員姓名、各自的代表 PR／Issue 及人工審查紀錄仍須依實際情況填入，不預填虛構貢獻。

- `index.html`：遊戲入口。
- `game/app.mjs`、`game/styles.css`：介面、輸入與畫面。
- `game/engine.mjs`：解謎、道具、場景與保存規則。
- `game/world.mjs`：地圖座標、碰撞、互動點與尋路。
- `content/story.json`：故事、謎題、道具及提示。
- `assets/maps/`、`assets/objects/`：現有候選素材；第一版採用相符部分。
- `assets/generated/`：本次新增圖檔、完整生成提示詞與設計紀錄。

## 素材與第一版限制

使用現有教室、走廊與互動物件；以內建 imagegen 補上廣播室、四方向角色、鑰匙與個人照。來源與生成紀錄見 [CREDITS.md](CREDITS.md)。圖書館與屋頂候選圖未增加為本版關卡。

必要廣播以字幕／文字稿呈現，音效為瀏覽器合成鐘聲；尚未製作真人配音。15–20 分鐘是設計目標，尚須真人初次試玩確認。瀏覽器自動化通關不等於劇情難度或玩家理解已由真人驗收。

## 靜態部署

入口使用相對路徑，無後端或建置需求。GitHub Pages 以 main 分支的 /（根目錄）為發布來源；.nojekyll 讓靜態 HTML、ES modules、JSON 與圖片直接發布。main 的更新會自動觸發重新部署，建置完成後玩家開啟同一網址即可取得新版本。發布後仍需在公開網址驗證素材、操作與通關流程。


## 新增探索：圖書館

完成走廊紀念名冊的姓名題後，走廊左側圖書館入口開放。借閱紀錄、未寄便箋與讀書會公告補充林予安的故事；支線可選，原本的解謎與八次鐘聲照常進行。三位 NPC 已更新為與主角一致方向的 Q 版像素造型。
